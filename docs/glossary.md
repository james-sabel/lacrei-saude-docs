# Glossário e referências

## Termos e siglas

- **API:** Application Programming Interface. Camada responsável pela comunicação entre sistemas.
- **Front-end:** Camada responsável pela interface utilizada pelas pessoas usuárias.
- **Back-end:** Camada responsável pelas regras de negócio e persistência de dados.
- **Endpoint:** Rota disponibilizada por uma API para execução de uma operação específica.
- **PostgreSQL:** Sistema gerenciador de banco de dados relacional.
- **Django REST Framework (DRF):** Framework utilizado para construção de APIs REST sobre Django.
- **JSON:** Formato textual utilizado para troca de dados entre sistemas.
- **ECS:** Elastic Container Service da AWS.
- **Fargate:** Serviço da AWS utilizado para execução de containers sem gerenciamento direto de servidores.
- **LGPD:** Lei Geral de Proteção de Dados do Brasil.
